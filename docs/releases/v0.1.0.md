# Canvas Student Assistant v0.1.0 · Windows x64 Portable

[English](#english) · [简体中文](#简体中文)

## English

Canvas Student Assistant is a Windows desktop companion for Canvas courses, assignments, announcements and deadlines, with local English-to-Chinese translation and optional ChatGPT assistance.

### Download and run

**[Download StudentAssistant-v0.1.0-windows-x64.zip](https://github.com/zzzbbb-hcc/canvas-student-assistant/releases/download/v0.1.0/StudentAssistant-v0.1.0-windows-x64.zip)**

Built for **Windows 10/11, x64**. No installer or Python installation is required.

1. Download the ZIP above. The automatically generated **Source code** archives are for developers.
2. Extract the entire ZIP.
3. Open the extracted `StudentAssistant` folder and run `StudentAssistant.exe`.
4. Keep `_internal` and `models` beside the executable. Moving only the EXE will leave the application incomplete.
5. Open **Settings → Canvas Connection** and enter your own Canvas Personal Access Token.

**This version supports the University of Sydney Canvas instance only.** It includes neither an account nor a shared Canvas Token. The interface currently uses a mixture of English and Simplified Chinese.

### Included features

- Read-only access to Canvas courses, assignments, announcements, Pages, Modules and available course materials, including in-app previews and explicit downloads.
- A separate Quizzes page for readable Classic and New Quizzes, with available quiz deadlines included in the dashboard and deadline list.
- Dashboard filters, assignment submission status, local-time deadlines and reminders while the application is running.
- Local announcement summaries, read/unread and starred markers, and offline English-to-Chinese translation for announcements and assignment introductions.
- Local content caching with background refresh, plus saved study conversations and course/custom conversation groups.
- Course-material retrieval and optional online answers after you connect your own ChatGPT account and allow the relevant content to be sent to OpenAI.

Deadlines use the values returned by Canvas. Quiz coverage depends on the APIs and permissions available to your account; the app does not start quizzes, read quiz questions or submit answers. Ed Discussion and Ed Lessons are outside this release's scope.

### Your connections and privacy

**The release contains no bundled personal data or saved Canvas Token.** It excludes the author's saved AI keys, OAuth credentials, personal databases, course caches, chat history and interface screenshots. Each user supplies their own Canvas Token in the app.

Credentials are stored through Windows Credential Manager. Your own settings, caches and saved conversations are created locally when you use the app. Offline translation runs on your computer. ChatGPT assistance requires your own browser sign-in and authorization, plus explicit permission to send the current question, relevant conversation history and selected course context to OpenAI.

ChatGPT availability depends on your account and workspace permissions. Complete sign-in and confirm a first online response with your own account. The app does not import credentials or conversations from Codex or other ChatGPT sessions.

Keep tokens and other secrets out of chat messages, screenshots and bug reports. See the repository's [security notes](https://github.com/zzzbbb-hcc/canvas-student-assistant/blob/main/SECURITY.md) for storage and data-handling details.

### Verify the download and retain attribution

Download [SHA256SUMS.txt](https://github.com/zzzbbb-hcc/canvas-student-assistant/releases/download/v0.1.0/SHA256SUMS.txt) and compare the ZIP's SHA-256 with its listed value. In PowerShell, from the download folder:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\StudentAssistant-v0.1.0-windows-x64.zip
```

The bundled offline translation model is Argos English-to-Chinese 1.9, derived from OPUS-MT. Attribution to Jörg Tiedemann and Santhosh Thottingal and the model's CC-BY 4.0 notice are included in `models/en_zh/README.md`. Keep that file and the bundled third-party notices with any redistributed copy.

Canvas Student Assistant 是一款 Windows 桌面学习助手，用于查看 Canvas 课程、作业、公告与截止时间，提供本机英译中，以及可选的 ChatGPT 辅助功能。

### 下载与运行

**[下载 StudentAssistant-v0.1.0-windows-x64.zip](https://github.com/zzzbbb-hcc/canvas-student-assistant/releases/download/v0.1.0/StudentAssistant-v0.1.0-windows-x64.zip)**

面向 **Windows 10/11 64 位（x64）** 构建，无需安装程序或 Python。

3. 打开解压后的 `StudentAssistant` 文件夹，运行 `StudentAssistant.exe`。

### 包含的功能

- 通过只读方式查看 Canvas 课程、作业、公告、Pages、Modules 和可读取的课程资料，支持应用内预览与用户主动下载。
- 独立的 Quizzes 页面，读取可访问的 Classic 和 New Quizzes，并将可获取的测验截止时间并入首页与截止时间列表。
- 首页筛选、作业提交状态、本地时区截止时间，以及程序运行期间的提醒。
- 本机公告摘要、已读／未读与星标，以及公告和作业介绍的离线英译中。
- 本机内容缓存与后台刷新，保存学习对话，支持课程分组和自定义对话分组。
- 检索课程资料；连接自己的 ChatGPT 账号并允许将相关内容发送给 OpenAI 后，可请求在线回答。

截止时间采用 Canvas 返回的值。测验覆盖范围取决于账号可访问的 API 和权限；程序不会开始测验、读取测验题目或提交答案。本次发布不包含 Ed Discussion 和 Ed Lessons。

### 连接自己的账号与隐私

**发布包不附带个人数据或已保存的 Canvas Token。** 包内不包含作者保存的 AI Key、OAuth 凭据、个人数据库、课程缓存、聊天记录或界面截图。每位使用者均需在应用内输入自己的 Canvas Token。

凭据通过 Windows Credential Manager 保存。使用过程中，你自己的设置、缓存和已保存对话会在本机创建。离线翻译在你的电脑上运行。ChatGPT 辅助需要你在浏览器中自行登录和授权，并明确允许将当前问题、相关对话历史和所选课程资料发送给 OpenAI。

ChatGPT 是否可用取决于你的账号和工作区权限。请使用自己的账号完成登录，并确认首次在线回答。程序不会从 Codex 或其他 ChatGPT 会话导入凭据或聊天记录。

请勿在聊天、截图或问题报告中放入 Token 或其他秘密。存储和数据处理细节见仓库的 [安全说明](https://github.com/zzzbbb-hcc/canvas-student-assistant/blob/main/SECURITY.md)。
